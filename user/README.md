# Пользовательские программы

Исходники сгруппированы по гостевому ABI:

- `w/` — PE32+ системные программы, DLL, Windows runtime и заголовки.
- `l/` — ELF launcher `startx` и его freestanding поддержка. Сторонние
  бинарники Alpine подготавливает `tools/StageAlpineXorg.py` в
  `build/alpine-xorg/`.

Гостевые тестовые DOS COM/MZ EXE и каталог `d/` удалены; поддержка DOS
остаётся в `kernel/dos/`.

Гостевые проверочные бинарники не включаются в FAT образ. Хостовые проверки
ядра находятся отдельно в `tools/checks/`.

В ядре интерфейсы совместимости разделены между `kernel/linux/`, `kernel/dos/` и native
`Nt*`. Общие файловые объекты и FAT находятся в `kernel/io/`.

В `cmd.exe` доступна `UNAME` — PE-команда из общего `cmdutils`-образа. Она
поддерживает `-a`, `-s`, `-n`, `-r`, `-v`, `-m`, `-o` и длинные эквиваленты.
`FASTFETCH` — настоящий ELF-бинарник fastfetch 2.44.0-r0 из официального пакета Alpine v3.22
(x86_64), запускаемый через musl loader; вместе с ним устанавливаются PCI ID
данные из `hwdata-pci`.

Интерактивный `cmd.exe` редактирует ввод посимвольно на native-консоли и в PTY:
поддерживаются Backspace/DEL, Delete, Home/End, стрелки и исправление строки
без смещения курсора после очистки хвоста. Команда `TERMINAL` открывает ещё одно
окно Xterm с отдельным `cmd.exe`; обычный запуск `xterm` также автоматически
использует `cmd.exe`. `START <program> [arguments]` запускает программу,
не блокируя текущую оболочку. Shell поддерживает `;`, `&`, `&&`, `||`, конвейеры
и перенаправление потоков. Tab выполняет дополнение имени из текущего каталога,
а Ctrl+C отменяет текущую строку ввода в приглашении. Каждое окно Xterm использует свою пару
Unix98 PTY master/slave; `chmod`/`fchmod` для devpts обрабатываются ядром.

Дополнительные сторонние ELF-программы из Alpine v3.22 подготавливаются отдельными воспроизводимыми staging-скриптами. `feh` (3.10.3-r0) добавляется через `tools/StageAlpineFeh.py`; вместе с ним в образ попадают musl-зависимости, модули загрузчиков Imlib2 и база `libmagic`. После сборки команда доступна как `/usr/bin/feh`.

Портативная сборка Windows 3.11 Rus работающая без установки, всего на одной дискете 1.44 mB. Работает сборка следующим образом: после включения компьютера с дискеты загружается MsDos, далее запускается утилита XMSDSK.EXE которая в области оперативной памяти создаёт виртуальный диск U объемом 5 mB. После этого на виртуальный диск с дискеты копируется архиватор PKZIP.EXE, распаковщик архивов PKUNZIP.EXE и сам архив с виндовсом WIN311.ZIP, который распаковывается и запускается Windows 3.11 Rus.


В файлах для загрузки доступны две сборки, они в принципе одинаковы, за исключением того, что одна из них может сохранять настройки и параметры системы, которые были изменены в процессе сеанса Windows. Если вас устраивают значения по умолчанию, которые были заложены в сборке, то загружайте Win311RuDS.img, а если вы хотите изменить фоновое изображение, цветовую схему, хранитель экрана... то загружайте Win311RuSS.img. Для сохранения настроек, которые были изменены, нужно не выключая компьютер выйти из Windows, в командной строке набрать SAVE и нажать Enter.

Краткие характеристики сборки:

- Язык - Русский (на английском только пару программ).
- Раскладка клавиатуры - Русская, Украинская, Английская.
- Переключение раскладки - Левый Shift + Правый Shift.
- Драйвер на PC Speaker (Скорость воспроизведения звуковых файлов зависит от частоты процессора, поэтому, настраивать работу этого драйвера нужно каждому индивидуально. Например, у меня два компьютера, на одном выставлено значение - 150, а на втором - 250. В этой сборке выставлено - 200. Для настройки нужно зайти на Панель Управления - Драйверы - Установка и нажать на Default, после чего автоматически вычислиться значения Speed именно для вашего ПК).
- Количество звуковых файлов - 4
- Количество хранителей экрана - 3
- Количество фоновых изображений - 5
- Количество программ - где то десяток.


Win311RuDS.img - Индекс DS в окончании имени файла расшифровывается как Default Setting (Настройки по умолчанию). Так как эта сборка запускается в области энергозависимой памяти, то естественно, что после перегрузки компьютера все данные и настройки не сохраняются. Если вам нужно изменять и сохранять настройки, то смотрите следующую сборку Win311RuSS.img
